# Betolla PLASMA Landing Page

Bilingual, responsive landing page for PLASMA hair care sets by Betolla Cosmetics.

## Features

- Arabic and English interface
- Interactive product ingredients, benefits, and directions
- Package-specific weekly care plan
- Responsive order form with automatic WhatsApp message
- Static, dependency-free build ready for Netlify

## Deployment

The repository is connected to Netlify. Publish directory: repository root (`.`).
